# Go Kafka WebSocket Demo

โปรเจกต์สำหรับศึกษาและทดลองพัฒนาระบบ Real-time ด้วยภาษา Go (Golang) โดยเน้นการเรียนรู้การรับส่ง Event ผ่าน Apache Kafka และการสื่อสารระหว่าง Server กับ Client ผ่าน WebSocket

## เป้าหมายในการเรียนรู้

- ศึกษาพื้นฐานการใช้งาน Apache Kafka
- ทำความเข้าใจ Producer และ Consumer
- ทดลองรับส่ง Event ระหว่างระบบ
- เรียนรู้การสื่อสารแบบ Real-time ด้วย WebSocket
- ฝึกเชื่อมต่อส่วนประมวลผล Event กับระบบ Real-time
- ทำความเข้าใจการออกแบบและแยกส่วนประกอบของ Backend

## เทคโนโลยีที่ใช้

- Go (Golang)
- Apache Kafka
- WebSocket

## วัตถุประสงค์

เพื่อพัฒนาความรู้ด้าน Go Backend Development, Event-driven Architecture และ Real-time Systems พร้อมนำความรู้ไปต่อยอดในการพัฒนาโปรเจกต์ Backend ในอนาคต
